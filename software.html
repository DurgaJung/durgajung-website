Mero Mandali Software – Available Features

Mero Mandali is a church presentation and worship software designed for Songs, Bible, Programmes, Media and Live Projection. It brings the main presentation tools needed for church services into one software.

Songs & Lyrics

  • Songs Library with Nepali and English/Romanized lyrics
  • Slide-by-slide song display
  • Add New Song with separate Nepali and English/Romanized text for each slide
  • Previous, Next, Add Slide, Delete Slide and Save Song controls
  • Song categories such as Bhajan, Chorus, Children’s Bhajan and Other Songs
  • Song search and song selection
  • Local MP3/audio support for songs
  • Song Preview and Live Projection

Bible & Programmes

  • Bible verse search and projection
  • Bible Preview before sending Live
  • Previous and Next Bible verse navigation
  • Programme presentation for church services
  • Programme slide navigation
  • Fast keyboard control for Bible and Programmes

Media & Projection

  • Photos/Image presentation
  • Video presentation
  • Media Preview and Live Projection
  • Timer feature
  • Separate projector/second-screen support
  • Select projection display
  • Open and Close Projector controls
  • Black Screen option
  • Welcome Screen option
  • Church Logo display
  • Mero Mandali Logo display
  • High Visibility / brighter projection mode
  • Projection brightness adjustment

Presentation Control Panel

  • Separate font settings for Nepali and English/Romanized text
  • Font size, color and bold controls
  • Text alignment and position controls
  • Line spacing and margin adjustment
  • Text shadow/outline for better visibility
  • Background color/image and overlay settings
  • Logo size and position controls
  • Presentation settings saved after restarting the software

Keyboard Controls

  • Songs: Left Arrow, Right Arrow and Enter
  • Bible: Up Arrow, Down Arrow and Enter
  • Programmes: Left Arrow, Right Arrow and Enter
  • Fast church presentation workflow designed for live services

Offline & Church Use

  • Offline operation for Songs, Bible, Programmes and saved media
  • Clean and professional church presentation interface
  • Designed to manage worship songs, Bible verses, service programmes, photos, videos and projector presentation from one software
