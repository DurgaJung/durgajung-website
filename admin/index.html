ACCESS CONTROL

Security

The admin page must be protected server-side. Never rely on a password stored in HTML or JavaScript.

Required now

  • Protect /admin/* using Cloudflare Access.
  • Allow only your own approved login identity/email.
  • Keep payment and licensing secrets out of GitHub.
  • Use the Secure logout button when using a shared device.

Later backend protections

  • Server-side Access token validation for privileged API actions.
  • D1 audit log for approvals, rejections and license resets.
  • Rate limiting for sensitive APIs.
  • Cloudflare Secrets for payment and signing credentials.
